# ILTO 

**Interactive Layout Tool** - веб-сервис для создания интерактивных карт и коллажей из изображений с выгрузкой в виде встраиваемого виджета.

## Технологический стек
* ЯП: TypeScript
* UI: Vue 3 (Composition API)
* Рендеринг: чистый WebGL2
* Бандлер: Rsbuild (Rspack-based)
* Тесты: Jest

## Теоретический базис
* Clean Architecture
* Framework agnostic
* SOLID
* DRY
* KISS
* ACID

## Основные архитектурные решения
* Реализация действий в системе основана на паттернах Команда и Макрокоманда
* Inmemory база данных состоит из коллекций документов по аналогии с решениями из NoSQL сферы
* Стуктура проекта представляет собой дерево, в котором родитель имеет ссылки на своих потомков
* Для пространственного поиска сущностей используется квадратичное дерево
* Сложные типы в системе являются объединением базового типа с несколькими вспомогательными
* Основой системы визуализации является тайловый движок


## Структура модулей
* **Core** - модуль, содержащий в себе хранилище данных, а также глобальные типы, интерфейсы и инструменты
  * **Stats** - состояние модуля базы данных
  * **Storage** - inmemory база данных, которая представляет собой плоские объекты, где id - это ключ, а значение это свойства записи
  * **Collection** - 
  * **Entity** - сущности, из которых состоит проект, такие как тайлы, маркеры и прочие
  * **Asset** - любые ресурсы, загружаемые пользователем

* **Viewer** - отвечает за отрисовку и взаимодействие с холстом
  * **Telemetry** - состояние модуля отрисовки
  * **Shear** - нарезка пользовательских изображений на тайлы
  * **ShaderColpiler** - компиляция шейдерных программ
  * **TextureManager** - загрузка изображений
  * **TextureAtlas** - загрузка изображений в виде текстур, разделенных на тайлы в GPU
  * **EntityPacker** - упаковка модельных матриц элементов и дополнительных параметров
  * **EntityPayload** - загрузка упакованнной информации о модельных матрицах и дополнительных параметрах элементов сцены в GPU
  * **TilePacker** - упаковка информации о текстурах элементов сцены
  * **TilePayload** - загрузка упакованнной информации о текстурах элементов сцены в GPU
  * **Scene** - формирование и хранение графа сцены
  * **EntityPass** - рендеринг сущноcтей сцены в рамках одного кадра
  * **Overlay** - менеджмент оверлея
  * **MathLibrary** - математические рассчеты

* **Editor** - это обертка для viewer, которая добавляет интерфейс и возможность редактирования проекта
  * **Session** - состояние сессии редактора


## Структура интерфейса
* **Editor**
  * **ActivityBar** - панель выбора активности
  * **UtilityBar** - панель для отображения набора утилит под выбранную активность
  * **WorkSpace** - рабоча область
    * **Viewer** - виджет, отвечающий за визуализацию проекта
  * **StatusBar** - отражение текущего состояния редактора
  * **ModalLayer** - слой для отображения модальных окон
