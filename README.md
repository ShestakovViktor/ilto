# **Interactive Layout Tool** 
веб-сервис для создания интерактивных карт и коллажей из изображений с выгрузкой в виде встраиваемого виджета.

## Архитектура

### Технологический стек
* ЯП: TypeScript
* UI: Vue 3 (Composition API)
* Рендеринг: чистый WebGL2
* Бандлер: Rsbuild (Rspack-based)
* Тесты: Jest

### Теоретический базис
* Clean Architecture
* Framework agnostic
* Transactional State Mutations
* SOLID
* DRY
* KISS

### Описание основных модулей
**Хранилище (Storage)**
  * Содержит ключевые типы сущностей, базу данных и инструменты для работы с ними 
  * Сложные типы являются объединением базового типа с несколькими вспомогательными
  * Данные хранятся в оперативной памяти (in-memory) в виде плоских коллекций документов на основе хеш-таблиц.
  * Коллекции реализованы как простые JS-объекты.
  * ID сущностей — это автоинкрементные числа, уникальные только в пределах своей коллекции.
  * Иерархия проектов реализована внутри плоской коллекции в виде ориентированного дерева с прямыми ссылками (от родителя к потомкам).
  * Данные о ресурсах представлены в виде независимых (плоских) документов.
  * Связи между сущностями и ассетами реализованы через внешние ссылки между коллекциями.

**Визуализатор (Viewer)**
  * Отвечает за отрисовку интерактивного холста и обработку взаимодействия с ним.
  * В основе визуализации находится тайловый движок.
  * Изображение формируется за счет трехпроходного (изображения, рамки, вспомогательные элементы) рендеринга.
  * Для вспомогательных элементов используется технология SDF.
  * Для пространственного поиска сущностей используется квадратичное дерево.

**Редактор (Editor)** 
  * Обертка над визуализатором, которая добавляет возможность редактирования проекта.
  * Главными элементами являются панель активностей и панель утилит.
  * Реализация действий основана на паттернах Команда и Макрокоманда


### Именование
Атомарные действия: Entity - Action - Specifier - "Action"

Комплексные сценарии: Entity - Action - Specifier - "Script"

Режимы ввода: Source - Specifier - Action - "Mode"

Виджеты панели утилит: Context - Role - View - "Widget"

## Спецификация
- [ ] Пользователь может создавать подложку проекта из загружаемых изображений.
- [ ] Пользователь может создавать интерактивные маркеры.
- [ ] Сервис позволяет экспортировать проект набора файлов для встраивания на сторонний сайт.
